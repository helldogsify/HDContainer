## Screenshot editor

- New tools: straight line, circle, text. Text is typed right on the picture and uses the same palette colours as drawing; the width buttons become three text sizes.
- A new arrow: tapered shaft and a swept-back head with rounded tips.
- Shift: 45-degree steps for lines and arrows, a perfect circle, a square.
- Redo (Ctrl+Y) next to undo, and one-letter tool shortcuts that work on any keyboard layout.
- New look: authored icons, rounded buttons, dark title bar, the picture on a dark stage with a soft shadow, size and hints in the bottom bar.
- Everything drawn is now smooth in the saved picture.

## Voice input

- Dictation now pastes into fields of apps built on WebView2 (such as Nexus Ai). It used to fall back to the clipboard there.
