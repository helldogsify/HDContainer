## Tray menu redesign, hotkeys for key scripts

**Tray menu**
- Screenshot, Video, Recorder and Devices are one row of four icons without captions; the name (or the time of a running recording) shows when you point at an icon. A running recording turns its icon red.
- New icon set drawn in one style: photo camera, video camera on a handle, record dot, devices. Sharp at any display scale.
- Devices is now the fourth icon: it unfolds your linked computers right under the icons (click again to fold). Without linked devices it opens Settings → Devices.
- The menu is narrower, and the "Key scripts" caption is gone (the script switches stay).

**Key scripts**
- Every script can have its own **Hotkeys** (the last line under "Only in"): they turn the script on and off, only in the script's programs. In the game chat a plain key stays a letter.
- A notice at the bottom right tells whether a script was turned on or off; a new option on the Key scripts page switches these notices off.
- A script with no programs chosen now works everywhere (it used to be blocked with "no program").
