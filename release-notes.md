- **Put icons in your own order inside a box**, like app icons on a phone: press an icon and move it — it lifts, the others glide aside to make room, and it settles into the gap when you let go. Near the top or bottom edge a long box scrolls. Drag it past the box edge and it becomes a normal drag to the desktop, another box or any app. The box remembers the order (**Sort → Custom order**); new files go to the end; picking name, type or date sorts again.
