- **Store app shortcuts keep their icon.** A shortcut to a Microsoft Store app (WhatsApp, for example) in a box could show a blank page after signing in again: Windows gives a blank picture for such a shortcut while the app's own icon is fine. Boxes now take the icon from the app itself. A picture Windows does not give at once (right after sign-in) is asked for again a few seconds later.
- **Boxes no longer jump into Open/Save dialogs.** An old-style Open/Save dialog holds a file view like the desktop's, and the boxes could take it for the desktop while it was open.
