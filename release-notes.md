## Choosing a program

- "+ Program" (hotkey exclusions in Settings -> Hotkeys, and key scripts) now opens a picker with the installed programs too, so a program no longer has to be running to be chosen. Running ones come first (marked with a dot), then programs from the Start menu, Steam and Epic Games; a search field filters by name or .exe; "Choose an .exe file..." is still there.
- One program = one row: for a game only its main executable is listed (the Unreal "-Shipping" exe where there is one), without launchers, anti-cheat, servers, crash reporters, updaters, uninstallers or Windows' own tools.

## Key scripts

- The time between keys is now counted from press to press, as other macro tools do; it can be random within a range or constant. Key hold is picked from the interval automatically, or set by hand. Old scripts keep their rhythm.
